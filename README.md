Executive-ready briefing site for the Blackbaud leadership discussion on Agentforce Coworker GA positioning, value, and rollout path.

- Context
- Dedicated capability page: Support Engineer Brief
- Dedicated capability page: Knowledge-Grounded Answers

- Dedicated capability page: Delegated Action Loop
- Capability Sequencing Map
- Salesforce Domain Summary
- External Research

- Sidebar capability search (left navigation)
- Persistent show/hide navigation control with saved state
- Bottom previous/next walkthrough flow links

## Local Preview

No build step is required.

Open `index.html` directly in a browser, or run a lightweight static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Replit Publish Flow

1. Import this GitHub repository into Replit.
2. Use a static deployment (or static web repl).
3. Enable password protection in Replit deployment settings.
4. Share the protected URL for executive session prep.
